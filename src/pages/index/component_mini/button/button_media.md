# ButtonMediaBase 组件介绍与应用

## 组件概述

`ButtonMediaBase` 是一个基于 Vue 3 的媒体控制按钮组件，用于管理媒体播放状态、语音状态以及语音输入状态。通过 `v-model` 双向绑定，可以方便地控制这些状态的变化。

## 组件属性

| 属性名      | 类型      | 描述                                 |
|-------------|-----------|--------------------------------------|
| `isPlaying` | `Boolean` | 控制媒体播放状态，`true` 表示正在播放，`false` 表示暂停。 |
| `isvoice`   | `Boolean` | 控制语音状态，`true` 表示语音开启，`false` 表示语音关闭。 |
| `voiceIng`  | `Boolean` | 控制语音输入状态，`true` 表示正在语音输入，`false` 表示未进行语音输入。 |
